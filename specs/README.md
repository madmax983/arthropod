## Lifecycle

1.  **Draft**: Initial spec, open for review.
2.  **Approved**: Reviewed and accepted for development.
3.  **In Progress**: Engineering is working on it.
4.  **Implemented**: Feature is live.
5.  **Deprecated**: Feature is replaced or removed.
