## 2026-06-29 - Widget Core Internal Module Encapsulation
**Tangle:** `widget-core/src/lib.rs` exposed 9 internal architecture modules (`form`, `layout`, `layout_bridge`, `primitive`, `context`, `input_state`, `layer`, `style`, `widget_trait`) as `pub mod`. This leaked the internal directory structure to all dependent crates, violating the strict `pub(crate)` encapsulation boundary rule and creating a "Sprawl" API surface.
**Blueprint:** Refactored the `pub mod` declarations to `pub(crate) mod` in `widget-core/src/lib.rs`. Maintained backward compatibility by explicitly re-exporting only the necessary cross-crate APIs via `pub use`, such as `layout_bridge::perform_layout` and `input_state::{ReactiveColorState, ...}`. Updated external usages in `arthropod`, `arthropod-ecs`, and `material-ui` to consume the clean, flattened API.
